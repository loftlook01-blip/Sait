# КАРКАС — сайт модульных домов

Сайт компании, которая производит модульные каркасные дома: сборка в цеху, доставка и монтаж по Архангельской области.
Дизайн — «бенто»-сетка в глубоком зелёном цвете по референсу; изображения домов — процедурные 3D-визуализации (Blender).

**Стек:** [Astro 7](https://astro.build) (статическая генерация) · TypeScript · чистый CSS · немного JS только там, где он нужен (конфигуратор, калькулятор ипотеки, фильтры, формы).
Сайт собирается в обычные HTML-файлы: быстро грузится, хорошо индексируется, подходит для любого хостинга.

## Быстрый старт

```bash
cd karkas
npm install
npm run dev       # http://localhost:4321
npm run build     # готовый сайт в папке dist/
npm run preview   # посмотреть собранную версию
npm run check     # проверка типов
```

Нужен Node.js 22+.

## Где что менять

Весь контент лежит в `src/data/`, вёрстку трогать не нужно:

- `site.ts` — **бренд, домен, телефон, мессенджеры, адрес цеха, реквизиты, ID Метрики, банки**. Все `TODO` заменить перед запуском.
- `models.ts` — дома: цены, площади, тексты, **планировки** (комнаты задаются прямоугольниками в метрах, план рисуется сам), комплектации, опции конфигуратора, тариф доставки (`FREE_KM`, `KM_RATE`).
- `cities.ts` — города доставки. Новый город = новый объект: страница, sitemap, карта, llms.txt и подвал обновятся сами.
- `content.ts` — факты первого экрана, вкладки «уютной жизни», этапы, пирог стены, ипотечные программы, сравнение, FAQ.
- `articles.ts` — статьи (HTML в поле `body`).

## SEO-модуль

- Отдельная страница под каждый коммерческий запрос: «модульный дом + модель», «модульные дома + город», «ипотека на модульный дом», «калькулятор стоимости».
- `title`, `description`, `canonical`, `robots`, Open Graph и картинка превью (`public/og.jpg`) на каждой странице.
- Микроразметка schema.org (JSON-LD), которая строится из тех же данных, что и страница:
  `HomeAndConstructionBusiness` (организация, адрес, координаты, зона обслуживания), `WebSite`, `Product` + `Offer` для каждого дома,
  `ItemList` каталога, `Service` + `areaServed` для городов, `FAQPage`, `HowTo` (этапы), `Article`, `BreadcrumbList`.
- `sitemap-index.xml` с приоритетами, `robots.txt` с `Clean-param` для Яндекса (UTM и параметры конфигуратора не плодят дубли).
- **YML-фид** `/feed.yml` — для товарной галереи в Яндексе, Яндекс Бизнеса и смарт-баннеров Директа.
- RSS `/rss.xml` — для Дзена и агрегаторов.
- Яндекс Метрика с целями: `lead` (заявка), `lead_open`, `calc` (конфигуратор), `mortgage`, `call`, `messenger`.
- Скорость: статический HTML, стили встроены, шрифт с предзагрузкой, картинки WebP с `srcset` и ленивой загрузкой.

## GEO-модуль

GEO здесь в двух смыслах — и для локального поиска, и для нейросетей (Generative Engine Optimization).

**Локальное продвижение**
- Гео-страницы `/goroda/<город>/` с уникальным текстом: местные грунты, дороги, посёлки и СНТ, своя стоимость доставки, свои вопросы.
- Гео-метатеги `geo.region`, `geo.position`, `ICBM` — на гео-страницах подставляются координаты города.
- `areaServed` с координатами в разметке, единые NAP-данные (название, адрес, телефон) на всех страницах.
- Карта доставки и перелинковка «строим рядом» между городами.

**Нейросети (Алиса, YandexGPT, ChatGPT, Perplexity)**
- `/llms.txt` — краткая выжимка: факты, цены, модели, города, статьи. `/llms-full.txt` — весь смысловой контент одним файлом.
- В `robots.txt` разрешены AI-краулеры (`YandexAdditional`, `GPTBot`, `OAI-SearchBot`, `PerplexityBot`, `ClaudeBot`).
- Статьи начинаются с блока «Коротко» с готовым ответом — его удобно цитировать; та же выжимка лежит в `abstract` в разметке `Article`.
- Конкретные цифры (цены, сроки, толщины, ставки) в тексте и разметке — нейросети охотнее ссылаются на точные данные.

## Заявки

Формы отправляют JSON на `/api/lead.php`, оттуда заявка уходит в Telegram и/или на e-mail; резервная копия пишется в `api/leads/`.

1. Скопируйте `public/api/config.example.php` в `public/api/config.php` (прямо на сервере, в git этот файл не попадает).
2. Создайте бота через @BotFather, впишите токен и chat_id.
3. Если на хостинге нет PHP, поменяйте `forms.endpoint` в `site.ts` на свой обработчик.

Если отправить не получилось, пользователь увидит телефон и мессенджеры — заявка не пропадёт молча.

## Изображения

Визуализации домов создаются скриптом на Blender (`scripts/render3d/`). Чтобы перерендерить или добавить модель:

```bash
pip install bpy==4.5.*            # Python 3.11
python scripts/render3d/render.py hero --w 1400 --h 1560 --samples 48 --out out/hero.png
python scripts/render3d/render.py model --opt variant=barn --w 1200 --h 900 --out out/model-barn.png
node scripts/images.mjs out       # PNG → public/images/*.webp + *-800.webp
node scripts/og.mjs               # og.jpg и иконки
```

Когда появятся реальные фото выставочного дома, цеха и построенных объектов, положите их в `public/images/` под теми же именами (`<имя>.webp` и `<имя>-800.webp`).
Настоящие фотографии — главный фактор доверия, добавьте их как можно раньше.

## Деплой

`npm run build`, затем залейте содержимое `dist/` на хостинг. Для Apache уже лежит `.htaccess` (HTTPS, кэш, сжатие, 404).
Персональные данные граждан РФ храните на серверах в России (152-ФЗ).
