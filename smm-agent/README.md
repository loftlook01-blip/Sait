# SMM-агент для группы ВКонтакте

Готовый «сотрудник» на базе Claude Code: ведёт группу мастерской мебели из массива и металла:
исследует конкурентов, планирует контент, пишет посты, верстает карусели, публикует в отложку,
отвечает на сообщения и комментарии, считает аналитику и сам корректирует стратегию.

```
smm-agent/
├── CLAUDE.md                  ← главная инструкция агента (роль, правила, распорядок)
├── routines.md                ← готовые промпты для расписания
├── brand/                     ← ЗАПОЛНИТЬ ВЛАДЕЛЬЦУ: бренд, голос, цены, FAQ
├── strategy/                  ← плейбук ниши (результаты анализа) и рубрикатор
├── .claude/skills/            ← 7 навыков: vk-research, content-planner, post-writer,
│                                 carousel-designer, vk-publisher, community-manager, analytics
├── scripts/                   ← vk.py (VK API), research.py (анализ), gen_image.py, render_carousel.mjs
├── templates/carousel.html    ← фирменный шаблон слайдов
└── data/                      ← память агента: план, черновики, идеи, инсайты, лиды, отчёты
```

## Запуск за 6 шагов

1. **Заполните `brand/`** — особенно `offer.md` (цены «от», сроки, гарантия) и TODO в `brand.md`.
   Пока там TODO, агент не называет цены и спрашивает вас.
2. **Положите реальные фото и видео работ** в `data/photos/<проект>/` и коротко опишите их в `data/photos/INDEX.md`
   (что за изделие, порода, размер, срок, можно ли называть цену). Это топливо для кейсов.
3. **Токены VK** → скопируйте `.env.example` в `.env`:
   - `VK_GROUP_ID` — числовой ID группы (Управление → Адрес → ID `club123456`);
   - `VK_GROUP_TOKEN` — Управление → Работа с API → Ключи доступа → создать (права: сообщения, управление, фото, стена);
     там же включите **Сообщения сообщества**;
   - `VK_USER_TOKEN` — ключ администратора группы с правами `wall, photos, groups, stats, offline`
     (через своё приложение на dev.vk.com, Implicit Flow). Нужен для постов, загрузки фото, статистики и поиска конкурентов.
   - Хранить `.env` только локально — он в `.gitignore`.
4. **Сеть.** Агенту нужен доступ к `api.vk.com` (и к сервису генерации картинок, если используете).
   В облачной среде Claude Code добавьте `api.vk.com` в разрешённые хосты среды.
5. **Проверка:** `python3 scripts/vk.py call groups.getById group_id=<ID>` и
   `node scripts/render_carousel.mjs data/carousels/example-wood/slides.json data/carousels/example-wood`
   (нужен Node 18+ и `npm i playwright && npx playwright install chromium`, если браузера нет).
6. **Запуск агента:** откройте Claude Code в папке `smm-agent/` (он прочитает `CLAUDE.md` и навыки) и скажите:
   «Проведи vk-research и составь план на неделю». Потом поставьте расписание из `routines.md`.

## Режимы безопасности
- `AUTOPUBLISH=0` (по умолчанию) — агент готовит посты в `data/drafts/` и ждёт вашего «ок». `1` — публикует в отложку сам.
- `AUTOREPLY=0` (по умолчанию) — ответы клиентам только черновиками в `data/drafts/replies.md`. `1` — отвечает сам.
  Рекомендуем первые 2 недели работать в черновиках, проверять тон и факты, потом включить.

## Что агент делает сам, а что — вы
| Агент | Вы / мастер |
| --- | --- |
| Исследование ниши, идеи, план | Фото и видео из цеха (агент присылает список «что снять») |
| Тексты, карусели, обложки, сценарии клипов | Публикация клипов из приложения VK (API ограничен) |
| Отложка постов, ответы в сообщениях и комментариях | Замеры, сметы, сложные/конфликтные диалоги (агент эскалирует) |
| Аналитика и отчёт по пятницам | Ответы на вопросы в `data/questions.md` |

## Честность контента
Агент не публикует нейросетевые картинки как ваши работы (только с пометкой «концепт»), не пишет фейковые отзывы,
не накручивает. Это и правила VK, и доверие клиентов — в нише мебели на заказ продаёт именно доверие.
