# Расписание агента (промпты для запуска по расписанию)

Время — МСК (Архангельск). Каждый промпт самодостаточный: агент сначала читает `CLAUDE.md`.
Запуск: расписание Claude Code (scheduled tasks / `/loop`), cron с `claude -p "<промпт>"` в папке `smm-agent/`, или вручную.

## Понедельник 10:00 — «Планёрка»
```
Ты SMM-агент из CLAUDE.md. 1) Навык analytics: коротко итоги прошлой недели, обнови data/insights.md.
2) Навык content-planner: план на текущую неделю в data/plan/. 3) Для каждого поста плана — post-writer и
carousel-designer, черновики в data/drafts/. 4) Навык vk-publisher: поставь в отложку (или, если AUTOPUBLISH=0,
пришли список на подтверждение). 5) В конце — сводка: что запланировано, что нужно снять в цеху, вопросы ко мне.
```

## Каждые 1–2 часа, Пн–Сб 9:00–21:00 — «Сообщения»
```
Ты SMM-агент из CLAUDE.md. Навык community-manager: проверь неотвеченные сообщения и комментарии за 3 дня,
ответь (или подготовь черновики, если AUTOREPLY=0), обнови data/leads.csv. Горячие лиды и эскалации — сразу мне
одной короткой сводкой. Если нового ничего — ничего не пиши.
```

## Ежедневно 18:00 — «Дозаправка»
```
Ты SMM-агент из CLAUDE.md. Проверь отложку (vk.py postponed). Если на ближайшие 3 дня меньше 2 постов —
доготовь из плана недели или банка идей. Ответь на комментарии к постам, вышедшим сегодня.
```

## Пятница 17:00 — «Отчёт»
```
Ты SMM-агент из CLAUDE.md. Навык analytics: отчёт недели в data/reports/ и пришли мне его текст (1 экран).
Включи: заявки, лучший/худший пост и почему, решение на следующую неделю, список съёмок для цеха, вопросы.
```
