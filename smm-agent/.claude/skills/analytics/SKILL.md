# Аналитика

## Сбор
```bash
python3 scripts/vk.py stats --days 7 > data/reports/raw-ГГГГ-ММ-ДД.json
python3 scripts/research.py collect <наш screen_name> --count 100   # для сравнения нас по lift, как конкурентов
python3 scripts/research.py report data/research/posts-ГГГГ-ММ-ДД.csv
```
Плюс `data/posts.jsonl` (рубрика/формат каждого поста), `data/leads.csv` (заявки за период), `data/replies.jsonl`.

## Метрики (в порядке важности)
1. **Заявки** (новые лиды в leads.csv, из них дошли до замера) — главная.
2. **Сообщения в группу** (новые диалоги).
3. **Охват / просмотры постов**, медиана по неделе.
4. **ERV** = реакции / просмотры (норма для ниши уточняется по нашим данным; ориентир — медиана конкурентов из vk-research).
5. Сохранения/репосты гайдов, комментарии вовлекающих постов, досмотры клипов (из статистики VK в приложении — попроси владельца скрин, если API не отдаёт).
6. Подписчики: прирост и отписки (резкие отписки после поста = сигнал).

## Разбор
- Топ-3 и антитоп-3 поста недели: почему (тема, крючок, формат, время, картинка). Сравни по `lift` относительно нашей медианы.
- По рубрикам и форматам: где больше охвата, где больше сообщений.
- Проверка гипотезы недели (из плана): подтвердилась / нет / мало данных.
