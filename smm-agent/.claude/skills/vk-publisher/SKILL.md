# Публикация во ВКонтакте

## Перед публикацией (чек-лист)
- [ ] Черновик прошёл самопроверку `post-writer`, картинки проверены глазами.
- [ ] Если `AUTOPUBLISH=0` в `.env` — **не публикуй**: статус черновика `готово`, сообщи владельцу список «на подтверждение»
      (дата, крючок, путь к файлу). Публикуй только после явного «да» — тогда с флагом `--force`.
- [ ] Время не ближе 3 ч к другому посту (`python3 scripts/vk.py postponed`).
- [ ] Нет персональных данных клиента в тексте и на фото (номера авто, адреса, лица без согласия).

## Команды
```bash
# в отложку на дату (МСК) — основной сценарий
python3 scripts/vk.py post --text-file data/drafts/2026-11-20-oak.md --photos data/carousels/2026-11-20-oak/0{1..7}.png \
  --at "2026-11-20 19:30" --rubric guide --format carousel --topic "выбор породы"

# опрос
python3 scripts/vk.py poll --question "Какое подстолье выбрали бы?" --answers "Чёрное" "Графит RAL 7016" "Белое"
python3 scripts/vk.py post --text-file … --photos 1.jpg 2.jpg --poll poll-123_456 --at "…"

# проверить отложку
python3 scripts/vk.py postponed
```
YAML-шапка черновика (`---…---`) срезается автоматически — в пост уходит только текст.
Фото загружаются в том порядке, в котором перечислены (первое — обложка в ленте). До 10 вложений.

## Клипы
VK API для загрузки клипов ограничен — клипы публикует владелец/мастер из приложения VK.
Твоя задача: сценарий, подпись, обложка, время, хэштеги → в `data/drafts/clips.md`, и напоминание владельцу в отчёте.
Если видео уже загружено в группу как ролик — его можно приложить к посту `--attach video-<group>_<id>`.

## После публикации
- Запись автоматически добавляется в `data/posts.jsonl`. Обнови статус в плане недели: `в отложке` / `вышел`.
- В первые 60 минут после выхода поста — проверь комментарии (`community-manager`) и ответь всем: это сильный сигнал для ленты.
- Отметь идею в `data/ideas.md` как `[x]`.

## Ошибки
- `[15] Access denied` / `[27]` — токен не тот (нужен пользовательский токен администратора с правами wall,photos) → `data/questions.md`.
- `[214] Access to adding post denied` — превышен лимит отложенных/постов в сутки (50) или стена закрыта.
- Ошибка сети к api.vk.com — сообщи владельцу, ничего не выдумывай, оставь пост в черновиках.
