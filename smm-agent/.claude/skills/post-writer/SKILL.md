# Тексты для ВКонтакте

Перед написанием: `brand/voice.md`, `brand/offer.md` (цифры), `strategy/playbook.md` §2–3.

## Структура поста (≈ 400–1200 знаков; гайд-карусель — 300–600, текст в слайдах)
1. **Крючок** — 1 строка, ≤ 90 знаков. Видна до «Показать полностью» — решает всё.
   Типы: цифра («68 кг дуба и 14 дней работы»), контраст («Клиент хотел 20 мм. Мы отговорили»),
   вопрос-боль («Почему столы из массива трескаются зимой?»), интрига/угадайка, прямая польза («Как выбрать…: 4 правила»).
2. **Контекст / задача** — 1–2 абзаца: для кого, что нужно было, какие ограничения.
3. **Суть** — решение / процесс / разбор. Конкретика: порода, толщина, размеры, покрытие, цвет RAL, срок, цена «от» (только из offer.md).
4. **Вывод / польза** — что читателю взять себе.
5. **Призыв** — один. Варианты:
   - заявка: «Напишите в сообщения слово СТОЛ (ЛЕСТНИЦА, ПРОЕКТ…) — пришлём расчёт за 1 день»;
   - комментарий: «А вы бы какой выбрали — 1 или 2?» / «Угадайте цену — ответ в комментариях вечером»;
   - сохранение: «Сохраните, пригодится, когда будете выбирать».
6. **Хэштеги** — 3–5 (см. voice.md).

## Шаблоны по рубрикам
**case:** Крючок с цифрой/задачей → «Задача» → «Что сделали» (3–5 пунктов с ▫️) → «Материалы и срок» →
«Цена такого стола — от … (зависит от …)» → призыв-заявка.
**process (подпись к клипу):** 1–2 строки + вопрос. Пример: «Первый слой масла — и дуб будто проснулся. Видели такое вживую?»
**guide:** крючок-польза → 1 абзац зачем → «Листайте карусель →» → итог в 2 строки → призыв сохранить/написать.
**engage:** короткая ситуация + 2 варианта (фото 1 и 2) + «Пишите цифру в комментариях — завтра расскажем, что выбрал клиент».
Ответить на каждый комментарий и опубликовать «разгадку» следующим постом/в комментарии.
**people:** имя, сколько лет в деле, чем гордится, одна живая цитата, фото за работой.
**review:** только реальный отзыв (текст/скрин от владельца) + фото работы + 1–2 строки контекста.
**sale:** повод (дедлайн, слоты, сезон) → выгода → условия из offer.md → срок действия → призыв.

## Сценарий клипа (15–45 с) — формат вывода
```
Название: …            Длительность: 25 с      Звук: ASMR цеха / трек «…»
0–2 с  КАДР: крупно искры сварки   ТЕКСТ: «Из этого будет стол»   (крючок!)
2–10 с КАДР: …                     ТЕКСТ: …
…
Финал: КАДР: стол в интерьере      ТЕКСТ: «Срок 14 дней. Расчёт — в сообщениях»
Обложка: кадр … + надпись «…» (≤ 4 слов)
Подпись к клипу: …
Что снять в цеху: список кадров, вертикально 9:16, без мата и музыки на фоне, 3–5 с на кадр.
```

## Опрос
Вопрос ≤ 80 знаков, 2–4 варианта, последний может быть «Свой вариант — в комментариях».
Создание: `python3 scripts/vk.py poll --question "…" --answers "…" "…"` → вложение в `post --poll`.

## Самопроверка перед сдачей (отметь все)
- [ ] Крючок цепляет без контекста и ≤ 90 знаков
- [ ] Все цифры есть в offer.md / brand.md (иначе — TODO и вопрос владельцу)
- [ ] Нет слов из чёрного списка voice.md, нет «лайкбейта»
- [ ] Один призыв
- [ ] Нейрокартинки подписаны «концепт/визуализация»
- [ ] Абзацы ≤ 3 строк, эмодзи ≤ 3

Сохраняй черновик в `data/drafts/ГГГГ-ММ-ДД-<slug>.md` с шапкой:

<текст поста>
