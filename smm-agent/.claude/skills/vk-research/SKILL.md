# Исследование ниши во ВКонтакте

Цель — не «скопировать конкурента», а понять, **какие темы × форматы × крючки** дают в нише
комментарии, репосты и сообщения, и адаптировать это под наш цех и Архангельск.

## Шаг 1. Список групп (`data/research/competitors.md`)
Если списка нет или ему больше 3 месяцев:
```bash
python3 scripts/research.py find "мебель из массива" "мебель из массива на заказ" "лофт мебель" \
  "мебель из металла и дерева" "стол из слэба" "стол из массива" "лестница на металлокаркасе" \
  "столярная мастерская" "дизайн интерьера"
python3 scripts/research.py find "мебель на заказ" "дизайн интерьера" "кухни на заказ" --city <id Архангельска>
```
Отбери 12–20 групп в 3 корзины и запиши в `data/research/competitors.md` (screen_name, участники, почему выбрана):
- **Федеральные лидеры ниши** (массив/лофт/слэбы, 10k+ участников) — учимся контенту.
- **Похожие мастерские 1–10k** из других городов — учимся, как маленьким набирать охват.
- **Локальные конкуренты** (Архангельск, Северодвинск) — следим за ценами, предложениями, частотой.
Отсекай: группы без постов последние 30 дней, перепродажу фабричной мебели, паблики-агрегаторы «идеи для дома»
(их можно 1–2 для идей, но помечай «агрегатор»).

## Шаг 2. Выгрузка и отчёт
```bash
python3 scripts/research.py collect <screen_name1> <screen_name2> ... --count 100
python3 scripts/research.py report data/research/posts-ГГГГ-ММ-ДД.csv --top 30
```
Скрипт считает:
- `lift` — во сколько раз реакции поста выше медианы своей группы (главная метрика: сравнивает группы разного размера);
- `ERV` = (лайки + комментарии + репосты) / просмотры × 100%;
- разрезы по формату, дню, часу, длине текста; топ по lift и по комментариям.

## Шаг 3. Смысловой разбор (делаешь ты, а не скрипт)
Открой CSV, прочитай `text` у топ-30 по lift и топ-15 по комментариям. Для каждого определи:
`тема` · `рубрика` (из `strategy/rubricator.md`) · `тип крючка` (цифра/вопрос/боль/контраст/интрига/цена) ·
`что вызвало комментарии` (вопрос в конце? спорная тема? цена? «угадай»?).

Сведи в таблицу паттернов и запиши в `data/insights.md` в раздел «Рынок, ГГГГ-ММ»:
```
| Паттерн | Пример (ссылка) | lift | Почему работает | Как сделать у нас |
```
Минимум 5 паттернов. Отдельно: «Что НЕ работает» (низкий lift при частой публикации).

## Шаг 4. Идеи
Добавь в `data/ideas.md` 10–20 идей в формате
`- [ ] [рубрика] [формат] Крючок — суть — какие фото/видео нужны от цеха — источник паттерна`.
Идеи, требующие съёмки, отметь `📷 нужна съёмка` — их список уйдёт владельцу в пятничном отчёте.

## Шаг 5. Обнови стратегию
Если данные противоречат `strategy/playbook.md` (например, у конкурентов лучше работают длинные тексты
или утро) — внеси правку с пометкой даты и ссылкой на отчёт. Доли рубрик меняй не больше чем на 5 п.п. за раз.

## Если API недоступен
Нет токена / сеть закрыта → не выдумывай цифры. Запиши в `data/questions.md`, что нужно (токен или доступ к api.vk.com),
и проведи качественный разбор вручную по ссылкам, которые даст владелец (скриншоты/тексты постов).
