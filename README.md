# Северная мастерская — сайт ремонта под ключ

Сайт компании по ремонту под ключ с собственным производством (столярный и сварочный цех, порошковая покраска).
Стартовый город — Архангельск. Архитектура сразу готова к расширению на другие города и регионы.

**Стек:** [Astro 7](https://astro.build) (статическая генерация) · TypeScript · чистый CSS без фреймворков · ~0 КБ JS на большинстве страниц.
Это даёт мгновенную загрузку, идеальную индексацию в Яндексе/Google и дешёвый хостинг (подойдёт любой, включая обычный PHP-хостинг).

## Быстрый старт

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # готовый сайт в папке dist/
npm run preview   # посмотреть собранную версию
npm run check     # проверка типов
```

Требуется Node.js 22+.

## Где что менять

Весь контент — в `src/data/`, вёрстку трогать не нужно:

- `site.ts` — **название, телефон, почта, мессенджеры, реквизиты, гарантия, ID Метрики**. Все `TODO` заменить перед запуском.
- `cities.ts` — города. Чтобы открыть новый город, добавьте объект и поставьте `active: true` — страницы, sitemap, выбор города в шапке и микроразметка обновятся сами.
- `services.ts` — услуги, цены «от», тексты, FAQ.
- `content.ts` — пакеты, прайс, преимущества, этапы, цеха, проекты, общий FAQ.
- `articles.ts` — статьи журнала.

### Фотографии

Сейчас вместо фото используются векторные иллюстрации (компонент `Art.astro`) — они выглядят аккуратно, пока нет собственных снимков.
Когда появятся фото объектов:

1. Положите их в `public/images/projects/<slug>/1.jpg, 2.jpg…` (лучше WebP/AVIF, ширина 1600–2000 px).
2. В `content.ts` у проекта укажите `photos: ['/images/projects/<slug>/1.jpg', …]` и поставьте `concept: false`.

Иллюстрация автоматически заменится фотографией. Реальные фото команды, цеха и объектов — главный фактор доверия, добавьте их как можно раньше.

### Отзывы

Блок отзывов намеренно не заполнен выдуманными текстами — поддельные отзывы вредят доверию и нарушают правила Яндекса.
Собирайте реальные отзывы в Яндекс Картах и 2ГИС, затем добавьте ссылки в `site.ts → listings`.

## Заявки

Формы отправляют JSON на `/api/lead.php` → Telegram и/или e-mail, плюс резервная копия в `api/leads/`.

1. Скопируйте `public/api/config.example.php` в `public/api/config.php` (на сервере, в git он не попадает).
2. Создайте бота через @BotFather, впишите токен и chat_id.
3. Если хостинг без PHP — поменяйте `forms.endpoint` в `site.ts` на свой обработчик (любой сервис, принимающий JSON).

Если отправка не удалась, пользователь увидит телефон и мессенджеры — заявка не теряется молча.

## Деплой

`npm run build` → содержимое `dist/` залить на хостинг. Для Apache уже лежит `.htaccess` (HTTPS, кэш, сжатие, 404).
Для хранения персональных данных граждан РФ используйте хостинг с серверами в России (152-ФЗ).

## Что заложено для SEO и GEO

- Отдельная страница под каждый коммерческий запрос: «услуга + город».
- ЧПУ-адреса, `canonical`, `sitemap.xml`, `robots.txt` с `Clean-param` для Яндекса.
- Микроразметка schema.org: `GeneralContractor` (организация, адрес, гео, зона обслуживания), `Service` с ценой, `FAQPage`, `BreadcrumbList`, `Article`.
- Гео-метатеги (`geo.region`, `geo.position`), уникальный локальный контент: районы, тип жилого фонда, климат.
- Open Graph и картинка для превью в мессенджерах и ВКонтакте.
- `llms.txt` и разрешения для AI-краулеров — чтобы нейросети (Алиса, ChatGPT, Perplexity) могли цитировать компанию в ответах.
- Скорость: статический HTML, предзагрузка шрифтов, минимум JS, анимации на CSS.
